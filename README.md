# SIA activity 3
   # Description:
        - This activity involves developing a Laravel-based CRUD system titled Egg_Market_Inventory_CRUD_System, which manages egg market inventory using a connected database. The system allows users to add, view, update, and delete records dynamically. A MySQL database was configured and connected through the .env file, and a migration was created to define the structure of the inventory table with multiple fields. The system uses a resource controller to handle all CRUD operations, including index(), create(), store(), show(), edit(), update(), and destroy(). Blade templates were used to build the user interface, including pages for listing records, adding new items, editing existing data, and viewing item details. The system ensures smooth navigation between all pages. This project demonstrates my understanding of database integration, migrations, and full CRUD functionality in Laravel using the MVC framework.

    - Title: Egg_Market_Inventory_CRUD_system
    - terminal: cd 'SIA activity 3' 
        - run: php artisan serve
